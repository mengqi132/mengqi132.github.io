把论文的代表性图片放进这个文件夹即可，文件名需与 publications.bib 中
figure 字段一致：

  figures/dypsi.png        <- DyPSI (NeurIPS 2026)
  figures/ariadne.png      <- ARIADNE (J. Imaging Inform. Med.)
  figures/geo-expert.png   <- Geo-Expert (ICML 2026 AI4S Workshop)

建议比例 4:3（如 1200x900），jpg/png 均可。
未提供图片时，网页会显示一个虚线占位框，不影响排版。

Drop a representative figure for each paper here, named to match the
`figure` field of its BibTeX entry in /public/publications.bib.
A 4:3 image (e.g. 1200x900) works best. Missing figures render as a
dashed placeholder slot, so the layout is safe either way.
